# SiteSafe-Sentinel v1.5.1

2026-09-27 · 桌面升级页面刷新修复

## 安装与使用

关闭旧软件后运行 `SiteSafe-Sentinel_Setup_v1.5.1_x64.exe`，选择原安装目录更新。
安装完成后使用原桌面快捷方式打开。便携版必须完整解压，不能仅复制 EXE。

## 本次修复

- 桌面入口按当前编译页面的内容摘要生成地址，避免继续加载升级前的 HTML。
- HTML 响应禁用缓存，不再因旧的条件请求返回 304；模型路径、业务数据和用户偏好不清空。
- 同步桌面健康接口、EXE 和前端版本为 1.5.1。
- 重新编译前端与 EXE，包含深蓝工业主题、黑白水墨主题和本地可旋转三维工地模块。

## 功能位置

首页工作台：工地作业区三维示意，支持拖动旋转、滚轮缩放、俯视和复位。
右上角主题按钮：切换深蓝工业 / 黑白水墨；系统设置中同样可以切换。
三维为通用演示布局，不是实测地图或 BIM。真实点位未标定时不自动投影。
八张示例的图片、掩码及报告继续保留。

## 新设备

基础 Python 和已编译前端随包提供，无需安装 Node 即可演示。
真实模型从「模型规则配置 → 新设备部署」配置；模型权重不随包提供。
本次为软件更新验证，不代表新增模型精度测试。安装器尚未签名。
