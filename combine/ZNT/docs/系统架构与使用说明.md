# 筑安智巡：系统架构与使用说明

筑安智巡把现场图像转成可复核的风险记录，并将图像证据、规范出处和工单处置放在同一工作台。本文对应 `main` 源码；公开安装器及其功能范围以 [v1.5.2 发布说明](https://github.com/Shrek2356/SiteSafe-Sentinel/releases/tag/v1.5.2)为准。

## 系统如何工作

```text
摄像头实时初筛 / 图片直接输入 / 定期全图检查
  → Qwen 开放风险发现与逐风险结构化
  → RiskSpec 定位任务 → SAM3 实体证据 → 程序关系检查
  → 风险描述与证据报告 + RAG 规范出处
  → 人工确认 → 指派整改 → 上传反馈 → 复验销项
  → 复盘统计与配置建议 → 管理员审批
```

| 模块 | 接收的信息 | 交给下一环节 |
|---|---|---|
| 多源感知与调度 | 视频抽帧、上传图片、巡检计划 | 原图、初筛区域提示、检测任务 |
| 视觉检测 | 原图与可用的初筛区域；模型发现的风险描述 | 风险类型、置信度、可见依据、辅助定位和待核实疑点 |
| RAG 规范检索 | 结构化风险与检索描述；已导入的规范 | 相关条款原文、版本、出处及引用快照 |
| 风险推理与协同处置 | 结构化风险、图像证据、规范引用 | 风险建议、待确认工单、确认和整改记录 |
| 复盘学习 | 风险记录、确认或驳回反馈、复验状态 | 复盘统计与阈值调整建议；审批后更新配置 |

### 视觉模块的分工

- **YOLO**承担实时端的目标初筛，不是全部入口的必经步骤。直接上传和定期全图检查保留独立入口。
- **Qwen**输出可见事实和风险候选。程序用 **RiskSpec** 将描述约束为实体、属性、位置和可执行的定位任务，并管理重复任务与调用预算。
- **SAM3**提供实体掩码、框和分数；程序计算空间关系、人员与防护装备的关联及可见性条件，再将证据组织成可复核结果。没有掩码时，仍可保留风险描述和疑点。
- **CLIP**提供可选的图像—提示词一致性辅助。本地生产基线默认关闭该开关；规范检索由知识库负责，不由 CLIP 完成。

### 规范与人工处置

知识库按文档解析与条文检索提供候选出处。规范管理支持解析预览、原文定位、版本与核验记录；引用随风险记录保存快照，便于之后追溯。未找到条款时仍可提示疑似风险，但不生成没有出处的规范结论。

风险推理、协同处置和复盘学习分别处理风险分级建议、工单流转、经验与配置提案。机器判断与安全员结论分开显示；复盘建议需要审批，并不直接训练或替换模型权重。

## 从哪里操作

| 目标 | PC 入口 | 说明 |
|---|---|---|
| 看三维工地与摄像头点位 | 首页工作台 | 源码版场景支持分区定位、模拟摄像头和无人机巡航；场景不用于推导真实坐标和距离 |
| 浏览既有案例与报告 | 检测结果汇总 | 可查看预置原图、标注和报告；不需要重新推理 |
| 检查新图 | 实时检测、检测任务中心 | 演示模式用于体验流程；真实检测需先配置模型环境 |
| 查看依据与处置 | 检测结果汇总、风险工单处置 | 对照图像与规范，完成确认、指派、反馈和复验 |
| 导入规范 | 模型规则配置 → 安全知识库管理 | 先预览解析结果，再导入并检索验证 |
| 复盘与审批 | 智能复盘分析、Agent协同学习 | 查看趋势与学习建议，管理员审批配置更新 |
| 部署或排查连接 | 模型规则配置 → 新设备部署；使用与支持 | 分别检查业务后台、检测桥与模型运行条件 |

## 安装和版本

- **Windows 安装版 v1.5.2**包含已构建前端与演示环境，可从[仓库首页](../../../README.md)下载。演示无需另装模型；真实检测的权重及运行环境另配。
- **`main` 源码（PC 端 1.5.3）**提供完整三维交互及源码启动入口。场景文件位于仓库根目录 [`3D`](../../../3D)，前端开发时读取该目录，构建时复制到 `pc-admin/dist/3D`。交互 HTML 与 GLB 的用途不同，见[场景接入说明](../../../3D/平台接入说明.txt)。
- **本机推理配置**从新设备部署向导开始；不要沿用开发机盘符。按[部署指南](../requirements/DEPLOYMENT_GUIDE.md)准备本机模型与依赖，最后用自己的图像验收。
