# 规范管理与证据报告使用说明

## 从哪里使用

1. 管理员登录，进入「模型规则配置 → 安全知识库管理」。
2. 点击「导入规范文件」；现在先出现解析预览，不会立即入库。检查条款编号、表格、跨页内容和扫描页警告，再点「确认导入」。取消不会修改知识库。
3. 在文件列表点击「解析预览 / 核验记录」，可下载当前源文件、查看全部解析片段和历史核验记录。
4. 管理员填写规范名称、版本、来源网址、效力结论、下次复核日期，以及核验依据/适用范围/修改原因，提交人工核验。账号身份取自后台登录，不由表单自行填写。
5. 已废止、被替代或被排除的文件不参与检索。到复核日期后显示提醒；它不是“已核实现行有效”的来源。
6. 用真实风险描述点击「检索验证」。相关度只是文本相似度；检索到条文不能自动证明照片违反了该条文。

## 实际文件的边界

目前正式检索来源仍是上一轮核对的《建设工程安全生产管理条例》8条节选、GB 55034-2022四条节选，不是整部规范的全文覆盖。
GB官方原PDF保留在算法目录 docs/standards/；其文字层乱码，因此没有以“导入成功”冒充全文可检索。上传同类文件会阻止入库并提示OCR。
人工批准来源是管理记录，不是系统自动法律认证。应检查官方网站的现行版本、修订/废止公告以及项目适用范围，不能凭模型记忆填条款。

## 结果、人工确认与报告

- 「检测结果汇总」将机器支持与人工结论分别展示；展开「规范检索证据」可查看来源、版本、条款、原文和哈希。
- 已入库真实事件显示「导出证据报告」，导出Markdown包含该事件所有风险及当时的引用快照，不重新检索。旧记录没有引用时明确提示缺失，不自动补造。
- 工单CSV增加模型观察、人工状态、规范检索状态及完整引用JSON列。复杂对象不再导出成 `[object Object]`。
- 移动端首页最新告警、告警详情、工单页均可展开规范证据。
- 一张图中只确认一条风险不会把其他风险改为已审核；全部审核后，至少一条确认则事件整体为confirmed，全部驳回则rejected。逐风险结论保留。
- 浏览器旧缓存中误标为“规范”的模型描述改为“旧记录未保存规范证据”，原描述保留在模型观察字段。

## 接口

以下业务接口沿用登录授权：

| 接口 | 用途 | 权限 |
|---|---|---|
| GET /api/knowledge/preview?filename=... | 全部片段、警告、哈希、核验历史 | 已登录查看者 |
| GET /api/knowledge/source?filename=... | 下载当前原文件，不接受任意路径 | 已登录查看者 |
| POST /api/knowledge/review | 提交人工核验，必须携带预览哈希及revision | 管理员 |
| GET /api/events/{event_id}/evidence-report | Markdown与完整事件快照 | 已登录查看者 |

本地检测桥增加 POST /api/detect/knowledge/preview-upload（multipart file），30MB上限，临时解析后清理，不入库。
原导入与删除仍由本地检测桥承担，不应将未加强访问控制的检测桥直接暴露公网。

## 留痕与限制

- 源文件同名替换/删除前留存 `.history/<sha256>/` 副本。
- 核验记录保存到 `.history/reviews/`，含账号、时间、理由、前一版元数据。版本与文件哈希绑定，过期表单被拒绝。
- 文件留痕不是防篡改存储；有本机文件权限的人仍可修改。需要生产级审计时应迁移至受保护数据库/对象存储。
- 当前PDF按页分块，预览可以逐页核对，尚未自动重组跨页条款；扫描件OCR全文、标准库全面扩充与逐条专业复核仍需真实材料和人工工作。
- 本轮是源码改动和构建验证，未重打EXE、未推送GitHub、未启动大模型。旧安装包不会自动包含这些修改。
