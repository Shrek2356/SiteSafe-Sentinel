# 八张示例重跑与摄像头展示

## 本机入口

运行 `E:\software\SiteSafe-Sentinel\SiteSafe-Sentinel.exe`，重新打开后使用：

1. 首页三维点位 → 查看该摄像头 → 对应的异常示例图片。
2. 实时视频监控 → 设备树 → 八个示例通道，可切换原图和本次标注。
3. 摄像头画面下方“查看过程与报告” → 本次真实检测任务，不会重新触发推理。
4. 检测结果汇总 → 查看实际入库的风险、疑点、规范引用；第 5 张以“本次未检出”单独保留。

若关闭了“展示素材”，摄像头静态示例不显示；真实视频流始终优先，播放失败也不会冒充示例图。
