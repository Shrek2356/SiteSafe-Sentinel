# SiteSafe-Sentinel v1.5.0

2026-09-27 · 三维工地总览与双主题桌面版

## 打开

安装版运行 SiteSafe-Sentinel_Setup_v1.5.0_x64.exe，安装后从桌面或开始菜单进入。
便携版完整解压后运行根目录 SiteSafe-Sentinel.exe，不要只复制 EXE。
基础 Python 与编译后的前端随包提供；不需要安装 Node 或大模型即可体验演示。

## 更新

- 本地三维工地示意，旋转、缩放、俯视、全屏、点位进入摄像头。
- 深蓝工业 / 黑白水墨双主题，右上角和系统设置可切换，自动保存。
- 字体 100%–200%，画面查看缩放 100%–400%。
- 真实结果图像与已保存规范引用对照窗口。
- 缓存容错、统一版本显示、取消视频固定位置的虚构框。
- 保留八个案例、原图、掩码、报告及已有模型链路。

## 模型部署

Windows 10/11 x64。安装器包含离线 WebView2，便携包要求设备已安装 WebView2。
真实检测从「模型规则配置 → 新设备部署」配置完整 Python、YOLO、Qwen、SAM3；CLIP 可选。
不含权重，不启动 GPU 推理；详细指导见 docs/桌面版v1.4.1模型部署说明.md。

## 升级与边界

安装器保留用户配置和知识库，不会自动覆盖旧知识库。升级前建议通过软件工作空间备份功能留存资料。
三维图为通用示意，不是测绘/BIM；真实点位未标定时仅列出，不生成假坐标。
软件回归不等于模型准确率评测。本次无新增模型测试。
安装器尚未签名，Windows 可能提示未知发布者。
